- 入手日：2026-11-27

## 注意（商標）

Instagram のロゴは Meta、X のロゴは X Corp. の商標です。Simple Icons の注意書き（DISCLAIMER.md）にあるとおり、
SVG データが CC0 でも商標の扱いは各社のブランドガイドラインに従う必要があります。このサイトでは次のように使っています。

- 自分のアカウントへのリンクとしてだけ使う（提携・推薦を思わせる使い方はしない）
- 形・比率を変えない、単色（黒）で表示する
- 小さく控えめに置き、まわりに余白をとる

公式の素材を使いたい場合は、各社の公式ページ（上記）からダウンロードした SVG にこのファイルを差し替えてください
（同じファイル名で置き換えれば、そのまま表示されます）。
